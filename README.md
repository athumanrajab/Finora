# Finora

Finora is a responsive digital banking website built with HTML, CSS, and vanilla JavaScript. It presents a modern financial experience focused on helping users move, manage, and grow their money.

## Features

- Responsive landing page for desktop, tablet, and mobile
- Smooth section navigation
- Account signup modal
- Interactive banking operations tabs
- Sticky navigation and section reveal animations
- Lazy-loaded images
- Testimonial slider with arrow, dot, and keyboard controls
- Dedicated About, Pricing, Terms, Privacy, Careers, Blog, and Contact pages
- Blog and Careers category filters
- Direct email and phone contact links

## Project Structure

```text
Finora/
├── index.html          # Main landing page
├── assets/img/         # Images, logos, icons, and illustrations
├── css/                # Stylesheets for the home page and standalone pages
├── js/                 # JavaScript interactions
└── pages/              # About, Blog, Careers, Contact, Pricing, Privacy, and Terms pages
```

## Run Locally

Install [Node.js](https://nodejs.org/) and `live-server` globally before running the project:

```bash
npm install -g live-server
```

Clone the repository, enter the project directory, and start the local server:

```bash
git clone https://github.com/athumanrajab/Finora.git
cd Finora
live-server
```

Then open:

```text
http://127.0.0.1:8080
```
